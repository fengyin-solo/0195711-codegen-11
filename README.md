# 中学生交互式光学设计编程项目

## How to Run

```bash
# Docker 运行（推荐）
docker-compose up --build -d

# 访问应用
# 用户端: http://localhost:8081

# 或直接用浏览器打开 frontend-user/index.html
```

| 服务 | 端口 | 说明 |
|------|------|------|
| frontend-user | 8081 | 光学设计交互应用 |

## 测试账号

本项目为纯前端应用，无需登录账号。

## 题目内容

制作一个面向中学生的交互式光学设计编程项目，要求以html格式开发 确保简洁易用 包含各种形状和材料的透镜 例如非球面透镜 低色散镜片 高折射率镜片等 具有可视化操控界面和2D光路实时渲染 系统应有第一次打开的引导界面和跨设备兼容性

## 测验题目与知识点维护

题目、知识点、答题提示统一维护在 `frontend-user/data/quiz-manifest.js` 中，调整题目**不需要修改任何页面代码**，刷新页面即可生效。

### 清单结构

- `questionTypes` / `difficultyLevels`：题型与难度枚举（中文名）
- `knowledgePoints`：知识点清单，每个知识点必须填写 `observable`，说明该知识点在实验中**能观察到什么现象**
- `questions`：题目清单，每道题必须标出：
  - `type`（题型）、`difficulty`（难度）
  - `knowledgePoints`（考查内容，引用知识点 id）
  - `requirements` / `validation`（达标条件与检查项）
  - `explanation`（答题后的解析，含 `correct` 及各检查项对应的失败解析）
  - `hints`（答题提示）

### 校验规则

页面加载时与容器构建时使用**同一套校验逻辑**（`frontend-user/js/quiz-validator.js`）：

- 清单条目缺少必填内容（如缺标题、知识点缺 `observable`、缺解析等）→ 给出说明并**跳过该条**
- 题目引用了不存在的知识点 / 题型 / 难度 → 给出说明并**跳过该条**
- 清单损坏或没有任何有效题目 → 视为致命错误，测验模式不可用（浏览器控制台报错；Docker 构建失败）

### 本地校验

```bash
# 本地开发时可随时运行，与容器构建时校验完全一致
node frontend-user/tools/validate-quiz.js
```

浏览器端打开页面后，控制台也会打印清单校验结果与被跳过条目的说明。


## 项目介绍

面向中学生的交互式光学设计学习工具，通过可视化方式帮助学生理解透镜成像规律。

### 核心特性

- 透镜类型：凸透镜、凹透镜、平面透镜、非球面透镜
- 特殊材料：低色散镜片、高折射率镜片、普通玻璃
- 2D光路实时渲染（Canvas 2D API）
- 首次使用引导界面
- 跨设备响应式布局（手机、平板、电脑）

### 光路规律

- 凸透镜：光线向光轴会聚
- 凹透镜：光线向外发散
- 平面透镜：不偏折
- 非球面透镜：更精准会聚，消除球差

### 技术栈

HTML5 + CSS3 + JavaScript（原生无依赖）
